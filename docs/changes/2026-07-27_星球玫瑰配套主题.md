# “星球玫瑰”配套主题

- 日期：2026-07-27
- 执行者：Codex
- 状态：本地验证完成，GitHub 独立预览分支已建立，正式环境未变更

## 做了什么

- 新增原创“星球玫瑰”主题，采用象牙白、炭黑细线、旧金色星点和少量玫瑰红。
- 重画 LoveHouse SVG App 图标，图案由小屋、玫瑰、星轨和星点组成。
- 新增最短 1.5 秒的开屏动画，账号状态读取期间显示星轨与品牌标记。
- 将登录、设置 PIN、PIN 解锁界面统一为极简线条卡片风格。
- 侧边栏使用同一枚品牌图标；默认主题切换为“星球玫瑰”。
- 保留原有恋爱小屋、浪漫蓝、复古手账和夜空紫主题，可随时切回。
- 更新 PWA 主色、描述与 Service Worker 缓存版本，确保新外壳能被更新。

## 为什么这样做

- 用户希望从桌面图标、开屏、密码门锁到小屋内部形成一整套配套视觉。
- 选择“小王子式的故事感”，但不复制参考图或现成角色插画，改为原创星球、玫瑰与小屋线稿。
- SVG 与 CSS 体积小，避免增加大量图片占用本机和仓库存储。
