# 星球玫瑰 2.1 图标、字体与玻璃卡片

- 日期：2026-07-27
- 执行者：Codex
- 状态：已完成，等待预览确认

## 做了什么

- 新增可复用的 `LineIcon` SVG 线性图标组件。
- 将侧边栏、手机底栏、快捷按钮、主题切换器、锁定按钮、天气卡和主要页面标题的小表情替换为线性图标。
- 将星球玫瑰主题的侧边栏、首页、正文、表单和按钮统一到同一套衬线字体栈。
- 将卡片、页面画布、侧边栏、顶部栏、底部栏和快捷面板调整为半透明玻璃效果。

## 为什么这样做

- 表情符号在不同手机系统上外观不一致，SVG 线条能保持统一的粗细、颜色和比例。
- 原版首页、侧栏和内容区混用了无衬线、宋体和 Georgia，视觉不够完整。
- 半透明表面可以保留星球与玫瑰背景的层次，同时维持文字可读性。
