# 2026-08-05 手机桌面v2 + 聊天界面

## 做了什么

### 1. 手机桌面 v2（Home.jsx 重写）

把首页从统一网格改为「滑动页面 + 混合组件网格」布局，参考"半醒手记"风格：

- **Hero 卡片**：T/K 头像 + 心跳线 + 在一起天数，做成圆角白底卡片
- **左右滑动两页**：CSS scroll-snap 实现，底部页面指示圆点
- **混合网格**：4列网格，APP 图标（1×1）和小组件（2×2）交错排列，grid-auto-flow: dense 自动填充
- **第一页**：Brain、Diary、时钟组件、Notes、Todo、语录组件、Mood、Search、Quotes、Private
- **第二页**：Theme、Log、天数组件、Clawd、Games
- **语录组件**：从 Supabase quotes 表随机抽取一条显示

### 2. 悬浮药丸导航

底部导航从贴边改为悬浮药丸形状：
- 居中浮动，圆角 26px，带阴影和模糊背景
- 去掉首页按钮，只保留 4 个：聊天/记忆/朋友圈/设置
- AppShell.jsx 同步更新

### 3. 聊天界面（全新模块）

新建 `src/modules/chat/` 模块：

- **ChatPage.jsx**：全屏聊天界面（z-index: 200 覆盖底部导航）
  - 气泡对话：左边 K（小克）右边 T（小婷）
  - 思考过程：每条回复前可展开/收起的 thinking block
  - 流式输出：实时显示 thinking 和 text 流
  - 个人面板：点击头像弹出底部面板，显示模型/对话轮数/会话起始/最近活跃
  - API 设置面板：可配置 API 地址、API Key、模型名
  - 清空聊天记录功能
- **chatService.js**：
  - localStorage 管理：聊天配置、历史记录、会话信息
  - 标准 Anthropic Messages API 流式调用（兼容 CC-P 代理）
  - 支持 extended thinking（content_block_start/delta 解析）

### 4. 其他改动

- LineIcon 新增 3 个图标：back（返回箭头）、send（发送箭头）、close（关闭叉）
- 路由 /chat 从占位页升级为真实聊天页面

## 为什么这样做

小婷要求把小屋做成"小手机"风格，参考了半醒手记的混合组件布局。聊天界面是为了嵌入 CC-P（Claude Code Proxy），让小婷可以在小屋里直接和小克聊天。

## 如何验证

- `npx vite build` 构建通过，无错误
- 静态 HTML 预览验证布局效果（Supabase 在此环境不可访问，数据读写未实测）
- 聊天 API 调用需要小婷填入 VPS 地址后实测

## 当前风险

- 聊天 API 的 CORS 配置——小婷的 VPS 需要允许 GitHub Pages 域名的跨域请求
- 聊天历史只存 localStorage，换设备会丢失（后续可考虑存 Supabase）
- CC-P 的流式格式可能与标准 Anthropic API 略有差异，需实测调整
