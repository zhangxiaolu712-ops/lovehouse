# 手机端象牙档案布局与通用组件

- 日期：2026-08-09
- 执行者：Codex
- 状态：SAFE_LOCAL / READY_FOR_REVIEW（仅本地前端改动，未上线）

## 做了什么

- 以当前小屋的象牙纸张、黑色衬线字、旧金细线和圆润白卡片为唯一视觉基准，没有继续使用玫瑰背景方案。
- 新增手机端通用组件：页面、页面标题、图标按钮、卡片、分区标题、状态标签和空状态。
- 将 Config 状态页迁移到通用组件，保留现有内容和层级，并修复门锁遮挡标题、长网址溢出、窄屏基础设施行挤压等问题。
- 将搭建日志和规划中占位页接入同一套页面组件，统一标题、卡片和空状态。
- 优化首页横向翻页：分页点可点击，触控区域扩大到 36px，并补充键盘焦点与当前页语义。
- 调整手机安全区和悬浮底栏间距，确保页面末尾可以滚动到导航上方，不被遮住。

## 为什么这样做

- 当前页面已经形成清晰的象牙档案册风格，继续叠加另一套主题会造成视觉和代码分叉。
- 把重复的标题、卡片、标签和分区收进一个共享文件，后续扩展页面时可以直接复用，减少内联样式和重复代码。
- 手机是当前主要使用端，需要优先保证窄屏换行、手指点击范围、安全区和固定导航下的内容可达性。
