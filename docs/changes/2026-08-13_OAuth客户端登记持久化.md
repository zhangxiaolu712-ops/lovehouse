# OAuth 客户端登记持久化

- 日期：2026-08-13
- 执行者：Codex
- 状态：本地实现与验证完成，等待复审；未部署生产

## 做了什么

- 新增服务端 `OAuthClientRegistry`，将动态注册生成的 OAuth client 从进程内 `Map` 移到独立文件仓库。
- 保存 `client_id`、redirect URIs、grant/response types、application type、token endpoint auth method、`created_at`、`expires_at`、`revoked_at` 与 client secret expiry。
- confidential client 的原始 secret 仍只在 DCR 响应中返回一次；仓库只保存以 `OAUTH_TOKEN_SECRET` 计算的 HMAC 摘要。
- client registry 使用 0700 私有目录、0600 状态文件、同目录文件锁、临时文件 fsync、原子 rename 与目录 fsync。
- 授权页、授权提交、authorization-code exchange 和 refresh 均从 registry 读取 active client；未知、过期、撤销、redirect 不匹配或 registry 损坏继续 fail closed。
- 保留原有 `response_type=code`、PKCE S256、resource/audience、scope 与 token auth method 校验，没有放宽 OAuth 边界。
