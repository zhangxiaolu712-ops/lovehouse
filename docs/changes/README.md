# LoveHouse 变更记录

这个目录专门保存 Codex、Claude Code（CC）和其他开发者对项目做出的实际修改。

## 强制要求

- 只要修改了项目文件，就必须留下记录。
- 一次任务建立一个 Markdown 文件，不把所有历史继续堆进同一个超长文件。
- 记录事实，不写无法确认的结果。
- 不在记录中放密码、密钥、令牌或真实私密数据。

## 文件命名

```text
YYYY-MM-DD_简短任务名.md
```

同一天任务名称相同时，在末尾增加序号。

## 记录模板

```markdown
# 任务名称

- 日期：YYYY-MM-DD
- 执行者：Codex / Claude Code / 人工
- 状态：已完成 / 部分完成 / 未完成

## 做了什么

- （填写）

## 为什么这样做

- （填写）

## 修改文件

- `path/to/file`：修改说明

## 数据库、环境变量与部署

- 无变化；或写清楚具体变化、是否已经应用到线上。

## 验证结果

- 已执行：
- 未执行：

## 已知风险或未完成事项

- （填写）

## 下一步计划

1. （填写）
```

## 阅读方式

开始新任务前，至少阅读本目录中最近的记录；涉及某个模块时，再搜索该模块名称阅读相关历史。
