# 2026-08-23 ChatGPT 两按钮卡片实验

## 目标

验证官方 ChatGPT（重点是 Android App）是否能通过 MCP Apps / Apps SDK 在对话中渲染 LoveHouse 自定义交互卡片，并让按钮选择回到当前对话。

## 范围

本轮只做隔离实验，不接入现有 LoveHouse 7-tool MCP 主链，不修改 Memory V2、OAuth、数据库、Nginx 或生产部署。

## 新增文件

- `experiments/chatgpt-choice-card/package.json`
- `experiments/chatgpt-choice-card/package-lock.json`
- `experiments/chatgpt-choice-card/server.mjs`
- 本变更记录

## 实现

- 使用 `@modelcontextprotocol/sdk` 与 `@modelcontextprotocol/ext-apps`。
- 暴露一个只读工具 `show_choice_card`。
- 工具通过 `_meta.ui.resourceUri`（同时保留 ChatGPT 兼容 alias `openai/outputTemplate`）绑定 `ui://lovehouse-choice-card/v1.html`。
- UI 资源 MIME 为 `text/html;profile=mcp-app`。
- 卡片只有两个按钮：`乖 😽` / `不乖 😑`。
- 按钮使用 ChatGPT 兼容的 `window.openai.sendFollowUpMessage()` 把选择作为用户后续消息送回对话；若宿主不暴露该 API，会在卡片内显示提示而不做其他动作。
- 服务仅监听 `127.0.0.1:3010`。

## 验证

已完成：

- `npm install` 成功。
- `node --check server.mjs` 通过。
- 本机 `/health` 返回 200。
- 临时 Cloudflare Quick Tunnel HTTPS 可达。
- MCP `initialize` 成功。
- `tools/list` 返回精确 1 个工具 `show_choice_card`，含 UI resource metadata。
- `resources/list` 返回 `ui://lovehouse-choice-card/v1.html`，MIME 正确。
- `tools/call` 返回结构化卡片数据。
- `resources/read` 能返回完整 widget HTML。

尚未完成：

- 真实 ChatGPT Android 客户端渲染验收。
- Android 客户端点击按钮后 `sendFollowUpMessage` 是否成功回到当前对话。

## 临时运行状态

实验服务以 PM2 名称 `lovehouse-choice-card-test` 临时运行，但没有执行 `pm2 save`，不会写入正式开机启动快照。

临时公网入口通过 Cloudflare Quick Tunnel 暴露，只用于本轮客户端验收；Quick Tunnel 不作为生产方案，也没有修改现有域名、Nginx 或 LoveHouse 主链。

## 风险与回滚

- 实验不访问任何 LoveHouse 私有数据，也没有认证、写入或开放世界能力。
- 停止 `lovehouse-choice-card-test` 并停止临时 cloudflared 进程即可完全撤回运行态实验。
- 删除隔离 worktree 即可撤回代码实验；原生产 checkout 未改。
