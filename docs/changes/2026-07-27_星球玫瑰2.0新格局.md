# 星球玫瑰 2.0 新格局

- 日期：2026-07-27
- 执行者：Codex
- 状态：已完成，等待独立预览确认

## 做了什么

- 重构“星球玫瑰”主题的应用外壳：增加顶部状态栏、5 位悬浮底栏、中央快捷房间面板和完整侧栏入口。
- 为该主题建立独立首页，不再沿用其它主题的卡片堆叠结构。
- 新首页包含大号恋爱天数、星球玫瑰线稿、周历、心情、天气、待办、语录、小屋索引和小克休息角。
- 为日记、记忆、语录、待办等现有页面增加统一的杂志档案页画布。
- 分别设计手机单列和桌面 12 栏响应式排版。

## 为什么这样做

- 原“星球玫瑰”主要改变颜色、背景和装饰，信息层级与其它主题基本相同，无法形成用户想要的“全新格局”。
- 新版把版式能力集中在 `AppShell`、`Home` 和主题 CSS，避免侵入每个业务模块的数据代码。

## 修改文件

- `src/shared/AppShell.jsx`：星球玫瑰专属顶部栏、底部导航、快捷房间和路由画布。
- `src/shared/Home.jsx`：新增星球玫瑰独立首页仪表盘。
- `src/themes/prince/style.css`：新增手机与桌面完整响应式版式。
- `docs/02_当前架构.md`：更新当前布局结构。
- `docs/06_待开发列表.md`：记录布局系统完成项。
- `docs/changes/2026-07-27_星球玫瑰2.0新格局.md`：本次变更记录。

- 当前只准备独立预览分支；在主人确认前不合并、不替换线上版本。
