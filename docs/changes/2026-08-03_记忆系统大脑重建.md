# 2026-08-03 记忆系统大脑重建

## 做了什么

按小婷的设计稿，重建了记忆系统（brain 表 + 大脑页面）。

### 数据库

- 新建 `brain` 表，统一存放所有记忆
  - 分类：记事（语录/总结/日记/长文）和 记感受（观点/修订/认/不认/悬置）
  - 生命周期：active → faded（淡忘）→ awakened（唤醒）→ archived（归档）
  - 支持：心情标记（晴/阴/雨）、特殊日标记、修正引用（ref_id）
- 迁移了 191 条数据：
  - quotes 82 条 → tag: 语录
  - memories 18 条 → tag: 总结
  - diary 59 条 → tag: 日记/总结/长文（按原 kind 分）
  - stream 24 条 → tag: 长文
  - mirror 8 条 → kind: 记感受，tag: 认/不认/悬置
- 旧表全部保留不动，brain 表记录了 source_table 和 source_id 可追溯

### 前端

- 新建 `src/modules/brain/brainService.js`：brain 表完整 CRUD + 搜索/随机/日历查询
- 新建 `src/modules/brain/BrainPage.jsx`：大脑主页面，匹配小婷设计稿
  - 头部：月份诗句 + 记录天数/记忆条数统计
  - 搜索栏：全文搜索
  - 双标签页：记事 | 记感受，各自带彩色标签筛选
  - 条目卡片：展开/收起、标记特殊日（⭐）、淡忘（💤）、唤醒（🔔）
  - 底部四色入口：特殊日（黄）/ 月历（蓝）/ 心情（粉）/ 盲盒（绿）
  - 月历：迷你日历组件，有记录的日期显示圆点
  - 盲盒：随机抽取一条记忆，可连续抽
  - 新建记录表单：按当前标签页匹配标签，支持心情选择
- 路由 `/brain` 注册
- 侧边栏记忆中心新增「大脑」入口（排在第一位）
- 手机底部导航「记忆」指向 `/brain`

### 记感受朋友圈+盲盒模式

- 记感受 tab 改为朋友圈式交互，不再列表加载全部感受
- 新增 FeelingTab 组件：
  - 镜子隐喻 UI（🪞），「翻一条」按钮随机抽取旧观点
  - 展示：原始观点 + 最早回应 + 最新回应（附回应总数）
  - 三键回应：认 / 不认 / 修订，以评论形式存入 brain 表
  - ref_id 自引用外键关联原始观点与回应
  - 可连续翻看，节省上下文和额度
- brainService 新增：getRandomFeeling, getFeelingReplies, getFeelingCount, addFeelingReply
