# 2026-08-09 · AI 启动记忆盲盒 V1

## 做了什么

- 新增 AI-facing `open_memory_box`，默认返回 3 条、最多 4 条随机旧记忆。
- 接入统一链路：`MCP Adapter → MemoryService → Repository → fixed actor RPC`。
- 新增独立 migration、rollback 和 disposable Supabase SQL 验证。
- 补齐 Bridge、权限伪造、disabled runtime、返回契约和 MCP 描述测试。

## 为什么

新对话中的 AI 在拿到 starter pack 与 House Rules 后，需要一个低参数入口随机回看过去，而不是只能按关键词“找最相关”。它可以接受旧理解、质疑、修订自己的私有记忆，或暂时不处理。

## 安全边界

- 合法候选集在 SQL 中先确定，再随机：仅 own private + approved Shared。
- 不读取另一 AI private、unapproved Shared、Legacy Pending 或其他 owner。
- actor 由 GPT/Claude 两个固定 RPC 名选择，客户端无 actor/space/namespace 参数。
- 返回当前确定 revision；四个版本字段与正文来自同一 revision row。
- Shared 保留真实 source revision 与 provenance，不伪造单一作者。
- 读取成功写入 `memory_box` 持久化审计，审计不保存正文。

## 没有做

- 不接旧 `brain` / FeelingTab 盲盒，不新增前端按钮。
- 不做 Dream、Curator、情绪聚类、记忆潮汐、认知状态机或跨调用去重。
- 不实现 VPS `onSessionStart()` 自动调用。
- 不部署、不改生产数据库/配置/密钥，不碰 Toy。
