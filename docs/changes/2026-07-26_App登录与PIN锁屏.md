# 可安装 App、账号登录与本机 PIN 锁屏

- 日期：2026-07-26
- 执行者：Codex
- 状态：草稿 PR 的 Cloudflare 预览已通过；主人账号、6 位 PIN 与个人数据 RLS 已验证，等待正式部署确认

## 做了什么

- 为完整 React 版 LoveHouse 增加 Supabase 邮箱账号登录门。
- 新设备账号登录一次后，设置本机 6 位 PIN；以后每次重新打开或刷新先输入 PIN。
- PIN 连续输错 5 次后清除本机 PIN，要求用账号密码重新登录。
- App 离开前台超过 30 秒自动锁定，并提供手动锁定按钮。
- 增加 PWA 安装清单、App 图标和仅缓存本站程序外壳的 Service Worker。
- Vite 改用相对资源路径，使同一构建可用于 GitHub Pages 子目录和 Cloudflare 根域名。
- 已为 10 张个人内容表启用只允许主人账号访问的 RLS，并把已执行的 migration 纳入仓库；`toy_commands` 明确排除且原策略未改。
- 增加 `wrangler.jsonc`，固定 Worker 名称、静态构建目录、SPA 回退和预览 URL，避免 Cloudflare 自动猜错部署目标。

## 为什么这样做

- 账号登录负责确认真实身份，PIN 只负责这台设备上的日常快速解锁，两者职责分开。
- 只加锁屏但不启用数据库 RLS 仍可被绕过，因此先记录家庭名单方案；权限脚本要等主人账号 ID 确认后再生成。
- Toy 现有 ADB 链路已经可用，本轮不改变其页面、表或控制逻辑。
- 沿用现有 GitHub/Cloudflare，不创建第三个托管地址。
