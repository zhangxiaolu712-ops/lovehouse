# LoveHouse 当前架构

一级模块：

- 空间中心
- 记忆中心
- AI中心
- 设备中心
- 项目中心
- 设置中心

设计理念：

**首页是房间。大模块是柜子。小功能是抽屉。**

---

## App 入口与门锁（已部署）

- `AuthGate` 位于所有页面之前：新设备先使用 Supabase 邮箱账号登录，之后每次重新打开或刷新使用本机 6 位 PIN。
- Supabase 登录会话保存在设备上；PIN 只在本机保存加盐慢哈希，不上传数据库。
- App 离开前台超过 30 秒会自动回锁，也可点击右上角手动锁定。
- `manifest.webmanifest` 与 `sw.js` 提供手机/桌面安装入口；离线缓存只保存本站程序外壳，不缓存 Supabase 数据。
- 启动时显示最短 1.5 秒的轻量开屏动画；App 图标、登录/PIN 门锁与默认主题统一使用原创“星球玫瑰”极简线条视觉。
- 第一阶段采用单主人模式：10 张个人内容表已启用固定主人账号 RLS；名单外账号即使登录也不能访问数据。
- 已执行的权限变更保存在 `supabase/migrations/20260726170157_secure_owner_only_rls_except_toy.sql`。
- Toy/ADB 链路本轮冻结，`toy_commands` 不在此次 RLS migration 内，原控制策略保持不变。

## 附注 · 代码目录结构

```
lovehouse/
├── src/
│   ├── main.jsx                 ← 应用入口
│   ├── core/                    ← 核心零件（可单独替换）
│   │   ├── supabase.js          ← Supabase 客户端（换数据库只改这里）
│   │   ├── theme.jsx            ← 主题切换（Context + localStorage）
│   │   └── router.jsx           ← 路由注册表
│   ├── modules/                 ← 功能模块 = 抽屉（每个独立，互不依赖）
│   │   ├── auth/                ← Supabase 账号登录 + 本机 PIN 门锁
│   │   ├── diary/ memory/ quotes/ todo/ mood/ stream/ changelog/
│   │   └── （每个模块 = xxxService.js 数据层 + XxxPage.jsx 页面）
│   ├── themes/                  ← 主题样式（prince/classic/cozy/vintage/desktop）
│   └── shared/
│       ├── AppShell.jsx         ← 应用外壳（桌面侧边栏 + 移动底部导航）
│       ├── Home.jsx             ← 首页（房间）
│       └── global.css           ← 全局样式
├── public/                      ← App 图标、安装清单、离线外壳
├── supabase/migrations/         ← 已执行并可复现的数据库权限变更
├── .env / .env.production       ← Supabase 配置
└── CLAUDE.md / docs/ / legacy/
```

## 附注 · 布局（响应式侧边栏格局）

- 桌面端（≥768px）：左侧固定侧边栏 — 品牌、恋爱天数、8 个页面导航、主题快捷切换
- 移动端（<768px）：底部导航栏，侧边栏隐藏

## 附注 · 数据库表

| 表名 | 字段 | 说明 |
|------|------|------|
| memories | id, content, category, importance, level, created_at | 记忆碎片，level 分固定/长期/短期/临时 |
| diary | id, title, content, mood, created_at | 日记本 |
| quotes | id, content, speaker, created_at | 语录墙 |
| todo | id, content, done, created_at | 待办事项 |
| mood_log | id, mood, note, created_at | 心情日志 |
| stream | id, title, content, created_at | 动态流 |
| notes | id, content, author, color, created_at | 小纸条留言板，author 默认"小婷"，color 默认"pink" |

注意：线上 10 张个人内容表已启用主人专属 RLS。`toy_commands` 是本轮明确冻结的设备链路例外，未修改其现有策略。
