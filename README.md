# LoveHouse

个人数字空间：Web 前端、未来 Android 原生外壳、Bridge / Provider、Memory V2、Engineering Workspace 与 Supabase 组成的一套长期可扩展系统。

## 施工入口

- 完整施工规则：`PROJECT_RULES.md`
- 当前架构、设备与服务住户表：`docs/02_当前架构.md`
- Codex 入口：`AGENTS.md`
- Claude Code 入口：`CLAUDE.md`

详细工程历史、阶段状态、错误经验和后续待办进入 Engineering Workspace；仓库不再维护每任务 change record、checkpoint 或窗口 handoff Markdown。

## 本地前端

```bash
npm install
cp .env.example .env
npm run dev
```

常用验证：

```bash
npm run lint
npm run build
```
